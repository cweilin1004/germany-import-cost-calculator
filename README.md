# 德國進口成本計算

此為獨立的本機網頁版，只保留「特貨空運－德國－良嵂」，不會讀取或改動原進口成本計算軟體的資料。

## 開啟方式

雙擊資料夾中的 `index.html`，或使用桌面上的「德國進口成本計算」捷徑。無需安裝伺服器或連線網路。

## 計算方式

- 德國商品可選擇打 9 折，折扣預設不勾選。
- 良嵂空運費預設 NT$180／kg，可在「運費設定」修改。
- 運費以商品重量 g ÷ 1,000 換算 kg。
- 含運單件成本＝折扣後商品台幣成本＋空運費。
- 毛利率請輸入百分比，例如輸入 `30` 表示 30%。
- 在結果頁輸入「預想成本」，建議批價＝預想成本 ÷（1－毛利率）。毛利率需小於 100%；預想成本會隨歷史紀錄保存。

試算結果可複製、儲存、查看、修改及刪除。設定及歷史紀錄保存在目前瀏覽器的 localStorage；請使用同一台電腦、同一個瀏覽器開啟。
